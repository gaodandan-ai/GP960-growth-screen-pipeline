# GP960 Growth Screen Pipeline

[中文版 (Chinese Version)](./README_zh.md)

A Python-based analysis pipeline for high-throughput microbial growth curve screening data generated by the GP960 system.

The pipeline converts raw plate-reader Excel files into standardized OD tables, cleans low-quality measurements, calculates stress-related fitness metrics, extracts growth features, and generates visual summaries for tolerant strain or gene screening.

## Features

- **Multi-Design Support**: Process GP960 raw `.xlsx` files into structured CSV tables for both single-replicate and triplicate experimental designs.
- **Data Cleaning**: Clean abnormal or low-growth curves using configurable OD thresholds.
- **Fitness Metrics**: Calculate relative fitness (RF), AUC-based RF, and comprehensive stress-tolerance scores.
- **Deep Feature Extraction**: Extract 50+ growth features, including maximum OD, AUC, growth rate, doubling time, and Gompertz model parameters.
- **Visualization**: Generate growth curves, correlation heatmaps, feature scatter plots, top-strain plots, and comparative dot plots.

## Working Principle

### 1. Data Standardizing
The pipeline parses GP960 raw Excel files (where time points are columns and wells are rows) into a "Tidy" format:
- **Time** becomes the index (rows).
- **Wells/Genes** become the columns.
- Data from multiple plates is merged into single CSV files for each experimental condition (e.g., Stress vs. Non-stress).

### 2. Data Cleaning & Filtering
To ensure analysis robustness, low-quality growth curves are filtered out:
- **Threshold-based**: Strains that do not reach a minimum OD (e.g., OD > 1.0) in non-stress conditions are flagged.
- **Abnormality Detection**: Curves with excessive noise or non-biological jumps are excluded from high-level fitness rankings.

### 3. Fitness Calculation (RF)
The core metric for stress tolerance is **Relative Fitness (RF)**, which normalizes mutant growth against its own non-stress performance and compares it to a control (Vector Control, VC):

$$RF = \frac{OD_{mutant, stress} / OD_{mutant, nonstress}}{OD_{control, stress} / OD_{control, nonstress}}$$

Beyond endpoint OD, the pipeline calculates:
- **AUC RF**: Based on the Area Under the Curve.
- **Rate RF**: Based on the maximum specific growth rate.
- **Comprehensive RF**: A weighted score (typically 40% OD + 40% AUC + 20% Rate).
- **Tolerance Score**: Comprehensive RF adjusted by a **Lag Phase Penalty** ($1/LagRatio$).

### 4. Growth Feature Extraction
Using `scipy.optimize` and `numpy`, the pipeline extracts 50+ features:
- **Logistic/Gompertz Fitting**: Extracts carrying capacity ($K$), growth rate ($r$), and inflection points.
- **Mu Calculation**: Maximum specific growth rate computed via sliding window log-linear regression.
- **Phase Detection**: Automated identification of lag, exponential, and stationary phases.

## Installation

```bash
git clone https://github.com/yourusername/GP960-growth-screen-pipeline.git
cd GP960-growth-screen-pipeline
conda env create -f environmental.yml
conda activate gp960_analysis
```

## Workflow Example (Single-Replicate)

### 1. Preprocess
```bash
python src/data_processing/single_replicate/01.pp_rawdata.py \
    --rawdata_dir data/raw/highmethanol \
    --plate_file data/raw/plate-gene-mapping.xlsx \
    --result_dir data/results/01.ppraw_data \
    --c1_label stress --c2_label nonstress
```

### 2. Clean
```bash
python src/data_processing/single_replicate/02.data_cleaning.py \
    --input_dir data/results/01.ppraw_data \
    --output_dir data/results/02.cleaned_data \
    --mapping_file data/raw/plate-gene-mapping.xlsx \
    --threshold 1.0
```

### 3. Analyze Fitness
```bash
python src/data_processing/single_replicate/03.calculate_fitness.py \
    --input_dir data/results/02.cleaned_data \
    --output_dir data/results/03.fitness_analysis \
    --rf_threshold_stress 1.05
```

## Output Structure

- `01.ppraw_data/`: Combined raw OD tables.
- `03.fitness_analysis/`: `stress_tolerant_genes.csv` (Ranked list) and distribution plots.
- `05.full_features/`: `all_features_raw_50plus.csv` (Master feature table).
- `09.plot_top5_curves_by_feature/`: PDF growth curves for the best performing candidates.

## Notes

- **Time Units**: Ensure consistency between scripts (Minutes vs. Hours).
- **Universal Reference**: Some advanced scripts support using a single "VC" column as a universal control for all plates.
- **Directory Compatibility**: The directory name `src/pipline/` is kept for system compatibility.
