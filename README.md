# GP960 Growth Screen Pipeline

A Python-based analysis pipeline for high-throughput microbial growth curve screening data generated by the GP960 system.

The pipeline converts raw plate-reader Excel files into standardized OD tables, cleans low-quality measurements, calculates stress-related fitness metrics, extracts growth features, and generates visual summaries for tolerant strain or gene screening.

## Features

- Process GP960 raw `.xlsx` files into structured CSV tables.
- Support both single-replicate and triplicate experimental designs.
- Clean abnormal or low-growth curves using configurable OD thresholds.
- Calculate relative fitness and comprehensive stress-tolerance scores.
- Extract 50+ growth features, including maximum OD, AUC, growth rate, and endpoint biomass.
- Generate growth curves, correlation heatmaps, feature scatter plots, top-strain plots, and dot plots.

Clone the repository:

```bash

cd GP960-growth-screen-pipeline
```

Create and activate a conda environment:

```bash
conda create -n gp960_analysis python=3.11
conda activate gp960_analysis
pip install pandas matplotlib seaborn scipy numpy openpyxl
```

## Workflow Overview

The main analysis workflow contains the following steps:

1. Raw data preprocessing
2. Data cleaning
3. Fitness calculation
4. Growth curve plotting
5. Full growth-feature extraction
6. Feature correlation and scatter plotting
7. Relative fitness matrix calculation
8. Top strain/gene screening
9. Top strain growth-curve visualization
10. Dot plot visualization

## Single-Replicate Workflow

Run each step from the project root directory.

### 1. Preprocess Raw Data

```bash
python src/data_processing/single_replicate/01.pp_rawdata.py \
    --rawdata_dir data/raw/single_replicate/highmethanol \
    --plate_file data/raw/single_replicate/plate-gene-mapping.xlsx \
    --result_dir data/results/single_replicate/highmethanol/01.ppraw_data \
    --c1_label stress \
    --c2_label nonstress
```

### 2. Clean Data

```bash
python src/data_processing/single_replicate/02.data_cleaning.py \
    --input_dir data/results/single_replicate/highmethanol/01.ppraw_data \
    --output_dir data/results/single_replicate/highmethanol/02.cleaned_data \
    --mapping_file data/raw/single_replicate/plate-gene-mapping.xlsx \
    --threshold 1
```

### 3. Calculate Fitness

```bash
python src/data_processing/single_replicate/03.calculate_fitness.py \
    --input_dir data/results/single_replicate/highmethanol/02.cleaned_data \
    --output_dir data/results/single_replicate/highmethanol/03.stress_tolerance_analysis \
    --rf_threshold_stress 1.05 \
    --comprehensive_rf_threshold_stress 1.05 \
    --rf_threshold_nonstress 0.95 \
    --comprehensive_rf_threshold_nonstress 0.95
```

### 4. Plot Candidate Growth Curves

```bash
python src/data_processing/single_replicate/04.plot_gene_od.py \
    --input_dir data/results/single_replicate/highmethanol/02.cleaned_data \
    --output_dir data/results/single_replicate/highmethanol/04.gene_growth_curves \
    --analysis_dir data/results/single_replicate/highmethanol/03.stress_tolerance_analysis
```

### 5. Extract Full Growth Features

```bash
python src/data_processing/single_replicate/05.calculate_full_features.py \
    --input_dir data/results/single_replicate/highmethanol/02.cleaned_data \
    --output_dir data/results/single_replicate/highmethanol/05.full_features
```

### 6. Inspect and Select Features

```bash
python src/data_processing/single_replicate/06.plot_raw_correlation_heatmap_exact.py \
    --input data/results/single_replicate/highmethanol/05.full_features/all_features_raw_50plus.csv \
    --output_dir data/results/single_replicate/highmethanol/06.plot_feature_selection
```

```bash
python src/data_processing/single_replicate/06.plot_raw_feature_scatter.py \
    --input data/results/single_replicate/highmethanol/05.full_features/all_features_raw_50plus.csv \
    --output_dir data/results/single_replicate/highmethanol/06.plot_feature_selection \
    --feat1 max_OD \
    --feat2 AUC
```

### 7. Calculate Relative Fitness Matrix

```bash
python src/data_processing/single_replicate/07.calculate_rf_matrix.py \
    --input_features data/results/single_replicate/highmethanol/05.full_features/all_features_raw_50plus.csv \
    --input_selected data/results/single_replicate/highmethanol/06.plot_feature_selection/selected_features_list.csv \
    --output_dir data/results/single_replicate/highmethanol/07.select_features_RF
```

### 8. Screen Top Strains or Genes

```bash
python src/data_processing/single_replicate/08.screen_top5_per_feature.py \
    --input data/results/single_replicate/highmethanol/07.select_features_RF/rf_matrix_final.csv \
    --output_dir data/results/single_replicate/highmethanol/08.top5_strains \
    --top_n 5
```

### 9. Plot Top Strain Curves

```bash
python src/data_processing/single_replicate/09.plot_top_strains_curves.py \
    --input_dir data/results/single_replicate/highmethanol/02.cleaned_data \
    --top5_file data/results/single_replicate/highmethanol/08.top5_strains/top5_strains_per_feature.csv \
    --output_dir data/results/single_replicate/highmethanol/09.plot_top5_curves_by_feature
```

### 10. Plot Dot Plot

```bash
python src/data_processing/single_replicate/10.plot_dotplot.py \
    --top5_file data/results/single_replicate/highmethanol/08.top5_strains/top5_strains_per_feature.csv \
    --output_dir data/results/single_replicate/highmethanol/10.dotplot
```

## Triplicate Workflow

Triplicate analysis uses the scripts in `src/data_processing/triple_replicate/`. The command structure is similar to the single-replicate workflow.

Example:

```bash
python src/data_processing/triple_replicate/01.pp_rawdata.py \
    --rawdata_dir data/raw/triple_replicate/thermal_k \
    --plate_file data/raw/triple_replicate/knockout_plate_gene_mapping.xlsx \
    --result_dir data/results/triple_replicate/thermal_k/01.ppraw_data \
    --c1_label nonstress \
    --c2_label stress
```

Then run steps `02` to `10` using the matching scripts in:

```text
src/data_processing/triple_replicate/
```

Example batch scripts are provided in:

```text
src/pipline/
|-- single_replicate_pipline.bash
|-- triple_replicate_pipline_thermal_k.bash
`-- triple_replicate_pipline_xianyang_k.bash
```

Before running a batch script, open it and update the input/output paths, condition labels, mapping file name, and threshold values for your own experiment.

## Data Privacy and GitHub Upload

This repository is configured to upload code and documentation only. The following files are ignored by default:

- Raw experimental data: `data/raw/`
- Analysis outputs: `data/results/`
- Python cache files: `__pycache__/`, `*.pyc`
- Local secrets: `.env`, `*token*`, `*password*`, `*.key`
- Generated figures and tables inside `data/results/`

Before committing, always check:

```bash
git status
```

If `data/raw/` or `data/results/` appears in the files to be committed, stop and update `.gitignore` before pushing to GitHub.
